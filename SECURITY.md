# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Use GitHub's private reporting: **Security → Report a vulnerability** on this repository.
Include steps to reproduce and the affected version. You can expect an initial reply within 7 days.

## Scope notes

LabScribber processes data files (JCAMP, spreadsheets, text) entirely on your machine and sends no data to external services.
Only open data files from sources you trust.
